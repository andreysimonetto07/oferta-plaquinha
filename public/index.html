FAQ

Perguntas
frequentes.

Ficou alguma dúvida?
Veja os detalhes antes do pedido.

Existe pedido mínimo?

Você pode comprar a partir de uma placa. Quanto maior o total do pedido, menor o valor por unidade.

Posso misturar os três modelos?

Sim. Somamos Google azul, Google preta e Instagram para definir a faixa do pedido. Todas as placas recebem o mesmo preço por unidade.

Como funciona o NFC?

A placa possui uma tag NFC. Após configurada, um celular compatível pode abrir o link por aproximação. Em aparelhos sem NFC, o acesso pode ser feito pelo QR Code usando a câmera.

Para onde a placa do Google deve direcionar?

Para o link de avaliações do estabelecimento no Google. O modelo Instagram deve direcionar para o perfil do negócio.

O QR Code é dinâmico?

Para alterar o destino sem reimprimir, a placa precisa ter um link intermediário e um serviço de gerenciamento. A loja deve confirmar esse recurso e fornecer as instruções de ativação antes da venda; esta versão não inclui uma plataforma de gestão de placas.

Como posso pagar?

Somente por Pix. Quando o pagamento estiver habilitado, o checkout gera um QR Code e o código Pix copia e cola. A confirmação é consultada junto à Mangofy.

Qual é o valor do frete?

O valor de referência configurado é R$ 19,90 por pedido, para todo o Brasil. Ele aparece separado no carrinho e deve ser confirmado pela loja antes de aceitar pagamentos.

Posso revender pelo preço que quiser?

Sim. Você define o seu preço de revenda, considerando frete, taxas, impostos e os demais custos do seu negócio.
